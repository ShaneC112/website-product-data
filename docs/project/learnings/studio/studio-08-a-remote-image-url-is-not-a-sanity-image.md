# Studio learning 08: A remote image URL is not a Sanity image.

- **ID:** `studio-08-a-remote-image-url-is-not-a-sanity-image`
- **Applies to:** `website-product-enrichment-sanity-studio`
- **Status:** Canonical learning detail.

## Learning

- A remote image URL is not a Sanity image. Product, swatch, and roomshot URLs need an explicit upload phase before document mutation.
