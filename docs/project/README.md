# Product Enrichment Project Documentation

This is the tracked cross-repository documentation source for the Website Product Enrichment workspace.

- `architecture/`: system intent, repository ownership, and data flow.
- `operations/`: safe operational procedures and approval boundaries.
- `learnings/`: indexed, evidence-backed engineering lessons.
- `scripts/`: reusable script catalog.
- `decisions/`: architecture decision records.
- `future/`: non-implemented design directions.
- `migration/`: documentation migration records.

Workspace-visible documentation and Copilot customizations are published from this repository with `npm run workspace:sync`.
