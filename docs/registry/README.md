# Registry

The [`registry`](../../src/registry/index.ts) export is the code-owned definition of product
extraction fields, product taxonomy, colour-family helpers, and image-generation profiles. It
provides stable keys, value shapes, publication metadata, and developer-defined category mapping.

Sanity receives an editor-facing projection of applicable registry fields; it is not the source
of truth for the registry.
